# ОКТАН

Сайт вымышленного автосалона ОКТАН: 3D-просмотр машин с выбором цвета, каталог с фильтрами, «гараж» с кредитным калькулятором и форма заявки.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Сайт. Шрифты Tektur, Manrope и JetBrains Mono встроены в файл (лицензия SIL OFL) |
| `vendor/three.min.js` | Библиотека Three.js r128 для 3D (лицензия MIT). Лежит рядом с сайтом, а не грузится с внешнего сервера |
| `privacy.html` | Шаблон политики обработки персональных данных |
| `consent.html` | Шаблон согласия на обработку персональных данных |

Сайт не обращается к сторонним серверам.

## Запуск

Откройте `index.html` в браузере или разместите папку целиком на хостинге. Папка `vendor` должна лежать рядом с `index.html`.

## Юридические документы

В `privacy.html` и `consent.html` заполните всё, что выделено жёлтым, удалите жёлтый блок «Это шаблон» и покажите текст юристу.

Форма заявки на сайте пока не отправляет данные в CRM, и в ней нет галочки согласия со ссылками на эти документы. Их нужно добавить перед запуском.

## Ограничения

- Модели машин стилизованные, построены в коде по реальным размерам.
- Цены и характеристики ориентировочные.
- Бренд вымышленный.
